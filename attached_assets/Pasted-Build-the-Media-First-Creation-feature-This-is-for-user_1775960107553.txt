THE API ROUTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FILE: app/api/generate/media-post/route.ts

POST body: {
  brandId,
  mediaUrls: string[],          -- Supabase Storage URLs of uploaded files
  mediaLabels: string[],        -- per-file "who or what is in this" labels
  mediaType: 'image'|'video'|'carousel',
  context: string,              -- main "what is this about" text
  existingCaption?: string,     -- if enhancement mode
  category: string,             -- realtor, food, wedding, automotive etc
  callToAction?: string,
  platforms: { platform: string, format: string }[],
}

For each platform in the platforms array, make a separate Claude call with:

SYSTEM PROMPT: (standard buildSystemPrompt with DNA + culture + voice + lessons)
Plus these additions based on category:

Property/Real estate category additions:
  "This is a property listing. Structure the caption as: compelling opening line about the property,
   key features as a scannable list, price and key practical details, strong call to action.
   Never fabricate room counts, prices, or features not mentioned in the context.
   Be aspirational but factual."

Food/Catering category additions:
  "This is food content. Make the caption sensory — describe how it smells, tastes, and looks.
   Use appetite-triggering language. If a recipe context is given, structure as: dish name,
   one-line description, key ingredients, call to action. Never invent ingredients not mentioned."

Wedding/Events category additions:
  "This is event content. If people's names are provided in the media labels, use them naturally
   in the caption — this personalisation is what the user wants. Structure as: warm opening
   referencing the people or event, description of the moment, emotional close, hashtags.
   Keep it celebratory and warm. Professional English — not overly casual."

Automotive category additions:
  "This is a vehicle listing. Structure: attention-grabbing opening (make/model/year),
   key features as bullets (engine, mileage, condition, colour, interior), price with
   negotiability note, call to action. Never invent specs not provided. Be factual and direct."

USER PROMPT for each platform:
"Generate a [platform] [format] caption for this content.

MEDIA DESCRIPTION:
[mediaLabels joined with context — e.g. 'Photo 1: The bride and groom, Amara and David. Photo 2: The wedding cake. Context: White wedding at Eko Hotel, Lagos, June 2026.']

[If existingCaption exists: 'The user has provided this existing description — enhance it, do not replace it entirely:\n[existingCaption]']

CALL TO ACTION: [callToAction or 'Engage with the post']

Platform requirements for [platform] [format]:
[insert exact platform rules from the quick-create route — same rules, reuse the same object]

Return JSON:
{
  hook: string (video formats only, else null),
  caption: string,
  hashtags: string[],
  keywords: string[] (YouTube only, else []),
  caption_char_count: number,
  platform_note: string
}"

Save all generated captions to generated_content table with content_type='media_post'.
Save media URLs and labels to the post record.
Return all platform captions as { platforms: { [platform]: GeneratedCaption } }

Run this SQL in Supabase:

CREATE TABLE public.media_posts (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  brand_id      UUID REFERENCES public.brands(id) ON DELETE CASCADE NOT NULL,
  user_id       UUID REFERENCES public.profiles(id) ON DELETE CASCADE NOT NULL,
  media_urls    TEXT[] DEFAULT '{}',
  media_labels  TEXT[] DEFAULT '{}',
  media_type    TEXT CHECK (media_type IN ('image','video','carousel','mixed')),
  category      TEXT,
  context       TEXT,
  existing_caption TEXT,
  call_to_action TEXT,
  generated_captions JSONB DEFAULT '{}'::jsonb,
  platforms_posted   TEXT[] DEFAULT '{}',
  post_status   TEXT DEFAULT 'draft',
  created_at    TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE public.media_posts ENABLE ROW LEVEL SECURITY;
CREATE POLICY "media_posts_own" ON public.media_posts
  FOR ALL USING (auth.uid() = user_id);
